# Teste manual controlado - Etapa 3

Use apenas uma conta e um contato autorizados para teste.

1. Iniciar o servico Node.js.
2. Acessar o painel Laravel.
3. Abrir `WhatsApp / Conexao`.
4. Inicializar o servico.
5. Gerar QR Code.
6. Ler o QR Code no WhatsApp.
7. Confirmar o estado `Conectado`.
8. Escolher um contato ativo, com telefone valido e sem `nao contatar`.
9. Escrever uma mensagem individual de teste.
10. Confirmar manualmente o envio.
11. Verificar o registro em mensagens de teste e eventos.
12. Reiniciar o servico Node.js.
13. Verificar restauracao da sessao.
14. Desconectar.
15. Reconectar.
16. Excluir a sessao.
17. Confirmar que novo QR Code passa a ser necessario.

Nao utilize dados de terceiros sem autorizacao.
