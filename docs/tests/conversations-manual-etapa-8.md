# Teste manual controlado — Etapa 8

1. Acessar o sistema como administrador.
2. Localizar o menu `CONVERSAS`.
3. Verificar o badge de não lidas.
4. Abrir o módulo.
5. Confirmar que o WhatsApp esta conectado.
6. Solicitar sincronização.
7. Acompanhar o status da última sincronização.
8. Visualizar chats importados.
9. Abrir uma conversa.
10. Conferir mensagens recentes.
11. Receber nova mensagem no telefone de teste.
12. Verificar atualização da conversa.
13. Responder manualmente pelo sistema.
14. Confirmar envio no WhatsApp.
15. Enviar mensagem pelo celular conectado.
16. Sincronizar novamente e confirmar importação como enviada.
17. Associar conversa a contato.
18. Atribuir responsável.
19. Alterar status.
20. Alterar prioridade.
21. Adicionar etiqueta.
22. Adicionar nota interna.
23. Arquivar e desarquivar.
24. Marcar contato como não contatar e confirmar bloqueio da resposta.
25. Testar em tela pequena.
26. Testar usuário sem permissão de sincronização.
